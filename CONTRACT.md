# Контракт проекта lambda

Этот файл — общая договорённость. Если нужно что-то изменить, сначала
пишем в чат, потом правим здесь, потом меняем код.

## 1. Типы ошибок (error_type)

Всего 5 вариантов, этого достаточно для КП2:

- `odz` — потеря ОДЗ, посторонний корень
- `non_equivalent` — неравносильный переход (возвели в квадрат, умножили на выражение с переменной и т.п.)
- `sign` — ошибка знака (перенос через равно, раскрытие скобок, смена знака неравенства)
- `arithmetic` — обычная вычислительная ошибка
- `none` — ошибки в решении нет

## 2. Формат задачи в датасете (data/dataset.json)

Список объектов, каждый выглядит так:

{
  "id": 1,
  "task": "Решите уравнение ...",
  "student_steps": ["шаг 1", "шаг 2", "шаг 3"],
  "error_step": 2,
  "error_type": "odz",
  "correct_answer": "..."
}

Правила:
- `error_step` нумеруется с 1 (это индекс в student_steps)
- если ошибки нет: `error_step: null`, `error_type: "none"`
- `correct_answer` — просто текст, кратко

Отвечает: Шамиль

## 3. Формат карточки знаний (data/knowledge/*.json или один общий файл)

{
  "id": "log_odz",
  "topic": "логарифмические уравнения",
  "title": "ОДЗ логарифма",
  "text": "Логарифм определён только при положительном аргументе и основании, не равном 1",
  "error_types": ["odz"]
}

Отвечает: Павел

## 4. State графа (src/lambda_tutor/state.py)

Один словарь/dataclass, который передаётся между агентами:

- task: str              — условие задачи
- steps: list[str]       — шаги ученика
- error_step: int | None — какой шаг ошибочный (определяет диагност)
- error_type: str | None — тип ошибки (определяет диагност)
- retrieved: list[dict]  — карточки, которые нашёл методист
- hint: str              — подсказка (пишет тьютор)
- hint_level: int        — 1, 2 или 3

Отвечает: Владимир

## 5. Интерфейсы агентов

Каждый агент — функция. Принимает state (или нужные поля из него),
возвращает ТОЛЬКО то, что сам обновил, остальное не трогает.

- diagnose(state) -> {"error_step": ..., "error_type": ...}
  Отвечает: Андрей

- retrieve(state) -> {"retrieved": [...]}
  Вход: error_type и/или тема задачи. Ищет по карточкам знаний.
  Отвечает: Павел

- tutor(state) -> {"hint": ..., "hint_level": ...}
  Использует error_type, retrieved и текущий hint_level.
  Не должен писать правильный ответ прямым текстом.
  Отвечает: Андрей

- llm.py — обёртка над Gemini, которой пользуются все агенты.
  Функция вроде call_llm(prompt: str) -> str.
  Отвечает: Владимир

## 6. Правила

- Ключи (.env) никогда не коммитим
- Каждый правит только свои файлы (см. раздел 5)
- Если нужно поменять формат — сначала в общий чат, потом сюда, потом в код
- Для КП2: только 3 агента (diagnose → retrieve → tutor), без SymPy и генератора задач
