# lambda

Мультиагентный сократический тьютор по профильной математике ЕГЭ.

**Команда №48 «lambda»**, НИЯУ МИФИ, Проектная практика

## Идея

Система разбирает решение ученика, находит шаг с ошибкой и ведёт его к верному ходу наводящими вопросами и контрпримерами, не выдавая готовый ответ.

## Архитектура (КП2: 3 из 5 агентов)

1. **Диагност** — находит шаг с ошибкой и её тип (`odz`, `non_equivalent`, `sign`, `arithmetic`, `none`)
2. **Методист** — ищет релевантные теоремы/методы в базе знаний по типу ошибки и теме задачи
3. **Тьютор** — формулирует наводящий вопрос или контрпример, не раскрывая ответ

Полный контракт форматов и интерфейсов — в [CONTRACT.md](./CONTRACT.md).

## Стек

Python, LangGraph, Gemini API (бесплатный тариф)

В разработке к следующим этапам: SymPy-верификатор, генератор задач, ChromaDB вместо поиска по ключевым словам, GigaChat как альтернативный провайдер.

## Запуск

1. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопировать `.env.example` в `.env` и вписать свой ключ:
   ```bash
   cp .env.example .env
   ```
   `GEMINI_API_KEY` — получить бесплатно на [aistudio.google.com](https://aistudio.google.com), раздел API keys. `GEMINI_MODEL` и `GEMINI_MODEL_FAST` можно оставить значения по умолчанию из `.env.example`.
4. Запустить бенчмарк из **корня проекта**:
   ```bash
   # Windows (cmd):
   set PYTHONPATH=src
   # Windows (Git Bash) / macOS / Linux:
   export PYTHONPATH=src

   python scripts/run_benchmark.py
   ```
   Прогон займёт несколько минут — модель бесплатного тарифа отвечает не мгновенно, а между задачами есть пауза, чтобы не упираться в лимит запросов в минуту.
5. Результаты: таблица метрик выведется в консоль и сохранится в `results/metrics.json` (сводные метрики + разбор по каждой задаче).

### Проверка графа без полного датасета

```bash
python -m scripts.test_graph
```
Прогоняет граф на одной тестовой задаче — быстрый способ убедиться, что всё собрано правильно.

## Датасет и база знаний

- `data/dataset.json` — 10 задач профильной математики ЕГЭ (уравнения и неравенства) с размеченными ошибками учеников, в формате из `CONTRACT.md`.
- `data/knowledge/knowledge.json` — 15 карточек с теоремами и методами, на которые опирается методист.

## Метрики (последний прогон)

См. [results/metrics.json](./results/metrics.json). Коротко: точность диагностики типа ошибки и устойчивость сократического диалога считаются на датасете из 10 задач и сравниваются по precision/recall/F1 для каждого типа ошибки.

**Известные ограничения прототипа:**
- Диагност иногда путает тип `odz` с другими типами ошибок — это первое наблюдение, доработка промптов запланирована.
- Поиск карточек знаний сейчас простой (по ключевым словам и типу ошибки), а не через векторный поиск — предстоит заменить на ChromaDB.
- Бесплатный тариф Gemini API имеет лимиты по запросам в минуту/день — на больших прогонах (50+ задач) понадобится либо растянуть прогон по времени, либо использовать несколько ключей.
- Тестов пока нет, граф проверяется через `scripts/test_graph.py`.
